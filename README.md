# 빈칸 학습지 생성기

지문을 붙여넣으면 핵심 내용을 골라 빈칸으로 재가공해주는 React + Vite 웹앱입니다.

## 주요 기능

- 텍스트 붙여넣기 또는 파일 드래그·드롭으로 원문 입력
- 빈칸 인식 레벨(L0 원문 그대로, L1 15%, L2 30%, L3 45%, L4 60%)로 빈칸 밀도 조절
- 공통/국어/영어/수학 특화와 국어 9품사·영어 8품사·수식 유형별 +50% 빈칸 가중치
- 자동 빈칸과 남은 후보를 뒤집는 역빈칸 생성
- 제목·주제·소제목·단원명·목차형 줄 자동 보존 및 줄별 개별 해제
- 미리보기 줄 번호를 클릭해 자동/항상 빈칸/항상 남기기 지정
- PDF의 그림·도표와 표 간격을 보존하고 항목별 포함/삭제 지정
- 모든 페이지의 그림·도표 전체 제거 및 전체 복원
- 그림·도표를 원문 세로 위치에 배치
- 모의고사형 2단 PDF를 좌표로 감지해 왼쪽 단부터 읽기
- 원문 배치와 페이지 수를 유지하는 원문 형식 인쇄
- 세로 1단·가로 1단·가로 2분할과 9~20pt 글자 크기를 지원하는 가독성 우선 인쇄
- 가독성 우선 인쇄의 빈칸에 매우 얇은 보조 밑줄 표시
- 브라우저 인쇄 창의 양면 인쇄와 호환되는 연속 페이지 출력
- 항상 빈칸으로 가리기 / 항상 그대로 남기기 어구 지정
- 채워쓰기 / 정답 공개 / 빈칸 편집 모드 + 정답 확인(채점)
- TXT·MD·HTML·Word·인쇄(PDF) 내보내기

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
