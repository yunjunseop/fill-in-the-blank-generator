# 빈칸 학습지 생성기

지문을 붙여넣으면 핵심 내용을 골라 빈칸으로 재가공해주는 React + Vite 웹앱입니다.

## 주요 기능

- 텍스트 붙여넣기 또는 파일 드래그·드롭으로 원문 입력
- 빈칸 인식 레벨(L0 원문 그대로, L1~L4)로 빈칸 밀도 조절
- 공통/국어/영어/수학/사회/과학 + 추천 카테고리(정의·개념어, 연표·수치, 인물·고유명사, 논리 연결어, 첫 글자만 남기기)로 특화 빈칸 생성
- 미리보기 줄 번호를 클릭해 자동/항상 빈칸/항상 남기기 지정
- PDF의 그림·도표와 표 간격을 보존하고 항목별 포함/삭제 지정
- 그림·도표를 원문 세로 위치에 배치하고 인쇄 시 원문 순서로 재구성
- 9~18pt 범위의 인쇄 글자 크기 조절
- 항상 빈칸으로 가리기 / 항상 그대로 남기기 어구 지정
- 채워쓰기 / 정답 공개 / 빈칸 편집 모드 + 정답 확인(채점)
- TXT·MD·HTML·Word·인쇄(PDF) 내보내기

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
